# 🚀 Project 1 - AWS EC2 Deployment with Terraform

## 📖 Overview

This project demonstrates how to deploy an AWS EC2 instance using Terraform (Infrastructure as Code).

## 🛠 Technologies Used

- AWS EC2
- Terraform
- AWS CLI
- Git
- GitHub Codespaces

## 📦 Resources Created

- EC2 Instance
- Security Group

## 📋 Terraform Workflow

```bash
terraform init
terraform validate
terraform fmt
terraform plan
terraform apply
terraform destroy
```

## 🎯 Skills Learned

- Infrastructure as Code (IaC)
- Terraform basics
- AWS IAM authentication
- EC2 provisioning
- Security Groups
- Git & GitHub workflow
